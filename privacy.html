Privacy policy

YouTube Clipper · last updated November 21, 2026

Who uses the app

YouTube Clipper is a personal tool run by its owner on their own Mac for their own YouTube channel. It has no other users.

What Google data it uses

With the owner's permission, the app uses the YouTube Data API and YouTube Analytics API to upload videos, set their titles, descriptions, captions and publishing times, and read view and like counts for the owner's own channel.

Where the data stays

The sign-in token and all video files, titles and statistics are stored only on the owner's Mac. Nothing is sent to any server run by the app, because there is none. The app does not sell, share or transfer Google user data to anyone, and does not use it for advertising.

Limited Use

YouTube Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the app's access at any time at myaccount.google.com/permissions, and delete the stored token by removing the app's folder on the Mac.

Contact

Questions: the support email shown on the app's Google sign-in screen.
